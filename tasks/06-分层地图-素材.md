## 1. 背景：投影对底图的要求

底图按经纬度 bbox 线性投影渲染（世界层为等距圆柱 Plate Carrée）：
```
x = (lng - west)  / (east - west)   * mapWidth
y = (north - lat) / (north - south) * mapHeight
```
因此**底图覆盖范围必须等于 seed 里该区域的 `geoBounds`**，且**实际像素宽高比必须匹配 `mapSize`**（过 `assertBoundsRatio`，含纬度 cos 修正），否则子节点投影会偏移。

已就绪参考：成都层底图已存在（`resources/assets/regions/region_chengdu/map.png`，2048×1400），可作风格基准。

| 区域 | regionId | geoBounds (W/E/S/N) | 投影类型 | 估值 mapSize | 期望宽高比 |
| --- | --- | --- | --- | --- | --- |
| 地球 | region_earth | -180 / 180 / -90 / 90 | 等距圆柱(Plate Carrée) | 2048×1024 | 2.000 |
| 亚洲 | region_asia | 25 / 170 / -12 / 82 | 线性(低精度) | 2048×1621 | ≈1.264 |
| 中国 | region_china | 73 / 135 / 18 / 54 | 线性(低精度) | 2048×1470 | ≈1.393 |
| 四川 | region_sichuan | 97 / 110 / 26 / 34 | 线性(低精度) | 2048×1455 | ≈1.407 |

## 3. 回填真实像素到 seed（关键）

公共部分写入的 `mapSize` 是**估值**。每张底图产出后：
- [ ] 取底图实际像素宽高，回填 `shared/src/seed/dataset.ts` 对应区域的 `mapSize`（earth/asia/china/sichuan）。
- [ ] 重跑 `npm run build:shared`。
- [ ] 对 earth/asia/china/sichuan 逐一调 `assertBoundsRatio(geoBounds, mapSize)`，确认 `ok=true`（偏差应 < 1%）。
- [ ] 若设计出图宽高比与期望差异较大，**以 geoBounds 为准调整出图尺寸**（不要反向改 geoBounds，否则破坏地理正确性）。
