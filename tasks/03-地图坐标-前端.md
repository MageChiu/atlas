## 0. 现状缺陷（要修的）
- Region 层未渲染任何底图（`SceneStage` 在纯色背景 `0x0f1115` 上画节点）。
- 景点用抽象像素 `Spot.coord:{x,y}`（随手摆），非真实地理位置。
- `regions/region_chengdu/map.png` 当前是城市照片，非可投影的地图底图。

## 1. 投影机制（实现依据）
经纬度 → 底图像素：
```
x = (lng - west)  / (east - west)   * mapWidth
y = (north - lat) / (north - south) * mapHeight     // 纬度朝上、像素朝下
```
**`@atlas/shared` 已提供现成纯函数，直接 import，不要自己重写：**
- `geoToPixel(geo, bounds, size): { x, y }`
- `assertBoundsRatio(bounds, size): { ok, ratio, expected, deviation }`（bbox 比例校验，含纬度 cos 修正）

来源：`shared/src/geo/projection.ts`，已从 `@atlas/shared` 顶层导出。
类型 `GeoPoint{lng,lat}` / `GeoBounds{west,east,south,north}` / `MapSize{width,height}` 也来自 `@atlas/shared`。

## 2. 数据契约（公共部分已就绪）
接口/seed 返回的 `Region` / `Spot` 已含：
- `Region.geoBounds?: { west, east, south, north }`、`Region.mapSize?: { width, height }`
- `Spot.geo?: { lng, lat }`（保留 `Spot.coord` 作兜底）

成都：`geoBounds = west 103.45 / east 104.25 / south 30.58 / north 31.05`，`mapSize = 2048×1400`。
8 景点经纬度见第 7 章。
