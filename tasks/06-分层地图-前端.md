## 3. 任务

### TF06-1 子区域按 geo 投影到父底图（`scenes/mappers.ts` + `SceneStage.tsx`）
- [x] `regionStateToNode` 增加"父上下文投影"定位，优先级（与设计 §4 一致）：
  ```
  子.geo + 父.geoBounds/父.mapSize 投影  →  RegionChildRef.coord  →  索引散布兜底
  ```
  建议签名扩展为 `regionStateToNode(region, index, coord?, parent?: Region)`：
  - 当 `parent?.geoBounds && parent.mapSize && region.geo` 齐全 → `geoToPixel(region.geo, parent.geoBounds, parent.mapSize)`。
  - 否则用 `coord`；再否则索引散布（现有逻辑）。
- [x] `SceneStage.tsx` 的 Region 层 `nodes` 计算：构造子区域节点时把**当前父区域** `region.region` 传入 `regionStateToNode(r, i, coord, region.region)`。
- [x] 子区域图钉也接入 `deOverlapNodes`（与景点同样防重叠），避免容器层多个子区域投影点重合。

### TF06-2 容器层底图渲染验证 / 兜底（`SceneStage.tsx`）
