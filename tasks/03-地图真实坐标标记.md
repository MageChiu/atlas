## 1. 投影机制（实现依据，所有轨道共识）
经纬度 → 底图像素：
```
x = (lng - west)  / (east - west)   * mapWidth
y = (north - lat) / (north - south) * mapHeight     // 纬度朝上、像素朝下
```
**bbox 比例强约束（含纬度 cos 修正，偏差 < 2%）**：
```
ratio = (east - west) * cos(latCenter·π/180) / (north - south)  ≈  mapWidth / mapHeight
```
成都 bbox（覆盖全部景点）：`west 103.45, east 104.25, south 30.58, north 31.05`
→ ratio ≈ 1.462 → 底图宽高比应 ≈ 1.462（如 2048×1400）。
